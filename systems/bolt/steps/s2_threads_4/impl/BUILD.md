## 4. Build and run

```

```

PALMA, the form this campaign actually ran

```

```

`levers.env` beside this file carries the runtime settings and the declarations the build checks. `logs/` carries this step's own measurement, and `../../MANIFEST.md` the machine, the target and the gate.
